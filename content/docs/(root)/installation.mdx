## Prerequisites

A React project with [Editframe](https://editframe.com/) set up. Components use `@editframe/react`.

## Install a free component

Browse the [component gallery](/components), then add a component through the shadcn CLI:

```bash
npx shadcn@latest add @framecn/caption-highlight
```

If you have not configured the registry namespace, use the full URL:

```bash
npx shadcn@latest add https://framecn.dev/r/caption-highlight.json
```

Import and use the copied component:

```tsx
import { CaptionHighlight } from "@/components/framecn/caption-highlight";

export function DemoVideo() {
  return <CaptionHighlight highlightColor="#f06292" />;
}
```

Files are copied to `components/framecn/<name>.tsx`. You own the code and can customize its text, timing, colors, and layout. Each component detail page includes its preview, controls, and source.

## framecn Pro

Components marked Pro, such as [Node Reveal](/components/compositions/node-reveal), have public previews, but source access requires signing in with an active Pro Annual, Lifetime, or Team plan. They are not included in the public registry; Pro subscribers install them with `npx shadcn@latest add @framecn-pro/<name>` (for example `@framecn-pro/node-reveal`) after configuring an API key as described in [Registry](/docs/registry#framecn-pro).
