## Prerequisites

A React project with [Editframe](https://editframe.com/) set up. Components use `@editframe/react`.

## Install a free component

Browse the [component gallery](/components), then add a component through the shadcn CLI:

```bash
npx shadcn@latest add @framecn/blur-reveal
```

If you have not configured the registry namespace, use the full URL:

```bash
npx shadcn@latest add https://framecn.dev/r/blur-reveal.json
```

Import and use the copied component:

```tsx
import { BlurReveal } from "@/components/framecn/blur-reveal";

export function DemoVideo() {
  return <BlurReveal text="Made for motion" />;
}
```

Files are copied to `components/framecn/<name>.tsx`. You own the code and can customize its text, timing, colors, and layout. Each component detail page includes its preview, controls, and source.

## Node Reveal Pro

[Node Reveal](/components/compositions/node-reveal) is the only Pro item. Its preview is public, but source access requires signing in with an active Pro Annual, Lifetime, or Team plan. It is not included in the public registry; Pro subscribers install it with `npx shadcn@latest add @framecn-pro/node-reveal` after configuring an API key as described in [Registry](/docs/registry#framecn-pro).
