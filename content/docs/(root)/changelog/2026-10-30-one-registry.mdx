---
title: October 30, 2026 - One registry for free and Pro
description: Pro components now install from @framecn; @framecn-pro and /r/pro are retired.
date: 2026-10-30
---

Every component, free or Pro, now installs from the `@framecn` registry. Pro components need your API key on that same entry:

```json
{
  "registries": {
    "@framecn": {
      "url": "https://framecn.dev/r/{name}.json",
      "headers": {
        "Authorization": "Bearer ${FRAMECN_API_KEY}"
      }
    }
  }
}
```

Then install with `npx shadcn@latest add @framecn/<name>`. Free components ignore the key.

If you set up `@framecn-pro` before, replace it with the entry above: `https://framecn.dev/r/pro/{name}.json` no longer serves components. See [Registry](/docs/registry#framecn-pro).
