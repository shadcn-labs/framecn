framecn v2 focuses the catalog on 27 typography components, 14 transitions, 15 captions, and one composition: Node Reveal.

- The site uses an app shell: a left sidebar with the Shadcn Labs project switcher, search, Components, Pricing, and Docs, with every component listed directly, plus a site footer linking [About](/about), Brand, Contact, and the legal pages.
- Browse free components in the [component gallery](/components) and filter them with category pills.
- Discover [Node Reveal](/components/compositions/node-reveal) in [compositions](/components/compositions). It is the only Pro item: previews stay public and source access requires a signed-in Pro account.
- Install free components from the public shadcn registry. Node Reveal is excluded from public registry payloads and markdown source exports.
- UI components, shaders, all other legacy catalog categories, and the former homepage showcase components have been removed from the repository.
- Pro plans are $179 annually, $249 lifetime, or $499 for a lifetime Team license. The first 50 Annual and 50 Lifetime buyers get early-bird pricing: $149 a year or $199 once.
- The interface uses Shadcn Labs' warm off-white with a black primary; bubblegum pink is reserved for brand highlights. Components live at `/components/<category>/<id>` and open a detail panel that slides out from the sidebar edge while the card preview morphs into a large preview, with the main sidebar still usable. The panel has Copy prompt (with agent-specific options), Customize (a sheet under the preview), Install, Code, and usage docs; Pro source shows an unlock dialog. Use the arrows (or ← →) to step through the section; click the preview backdrop, press Escape, or use Close to return to the grid.
- Component documentation lives in the detail panel instead of /docs. Old /docs/components URLs redirect.
- Pro members can generate a personal API key and install Node Reveal with `npx shadcn@latest add @framecn-pro/node-reveal`.
- Passwordless sign-in, persistent Pro entitlements, verified Dodo payment events, and customer billing management are available. Checkout requires a registered deployment webhook before accepting payments.
- The homepage is a landing page: “Beautiful videos, made simple” with an install command, a live showcase, categories, how it works, Node Reveal Pro, and an FAQ. The full gallery lives at [/components](/components).
