## Self-contained scenes

framecn components are React scenes built with [Editframe](https://editframe.com/). Captions, animated text, and compositions can be copied into your project and combined on a video timeline.

## Timing

Components expose timing through props such as `fps`, `durationInFrames`, and `speed`. Their Editframe animations follow the composition timeline, so previews and rendered frames use the same motion. Consult each component API reference for its supported controls.

## Customization

Use the [component gallery](/components) to explore previews. Adjust available controls on a component detail page, then copy its source and customize the props in your project. The copied source belongs to you; there is no separate framecn UI core to install.

## Free and Pro components

Caption components are free to install from the public registry. Pro components — animated text, carousels, 3D globes, collages, charts, scroll animations, and compositions such as [Node Reveal](/components/compositions/node-reveal) — have public previews; their source is available to signed-in customers with Pro access.
