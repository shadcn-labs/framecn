The framecn public registry contains typography, transitions, and captions built with Editframe. [Node Reveal](/components/compositions/node-reveal), the only Pro composition, is installed from the authenticated `@framecn-pro` registry (see [framecn Pro](#framecn-pro)).

## Setup

Add this namespace to your `components.json` registries:

```json
{
  "registries": {
    "@framecn": "https://framecn.dev/r/{name}.json"
  }
}
```

## Usage

Install a free component by its registry name:

```bash
npx shadcn@latest add @framecn/blur-reveal
```

Without a registry alias, use the full URL:

```bash
npx shadcn@latest add https://framecn.dev/r/blur-reveal.json
```

Components install into `components/framecn/` and depend on `@editframe/react`. Browse the [component gallery](/components) for previews and installation details.

## framecn Pro

Pro subscribers can install [Node Reveal](/components/compositions/node-reveal) with the shadcn CLI using a personal API key.

1. Open the Node Reveal panel while signed in and generate an API key. It is shown once — copy it.
2. Add the key to your project's `.env`:

```bash
FRAMECN_API_KEY=fcn_...
```

3. Add the `@framecn-pro` registry to `components.json`:

```json
{
  "registries": {
    "@framecn": "https://framecn.dev/r/{name}.json",
    "@framecn-pro": {
      "url": "https://framecn.dev/r/pro/{name}.json",
      "headers": {
        "Authorization": "Bearer ${FRAMECN_API_KEY}"
      }
    }
  }
}
```

4. Install:

```bash
npx shadcn@latest add @framecn-pro/node-reveal
```

Regenerating a key immediately invalidates the previous one. Requests fail with 401 for a missing or invalid key and 403 without an active Pro plan.
