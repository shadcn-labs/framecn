## Usage

```tsx
import { NodeReveal } from "@/components/framecn/node-reveal";
```

```tsx
<NodeReveal />
```

The two words read as one line, then a node grows between them and drives them
apart. Nothing animates the text — its position is a consequence of the node's
size.

```tsx
<NodeReveal src="/logo.png" lead="SHADCN" trail="LABS" size={520} />
```

### REVEAL_EASINGS

The node enters from nothing rather than morphing in place, so every preset is
from the ease-out family, sorted weak to strong.

| Name     | Value                                  |
| -------- | -------------------------------------- |
| `quad`   | `cubic-bezier(0.25, 0.46, 0.45, 0.94)` |
| `cubic`  | `cubic-bezier(0.215, 0.61, 0.355, 1)`  |
| `quart`  | `cubic-bezier(0.165, 0.84, 0.44, 1)`   |
| `quint`  | `cubic-bezier(0.23, 1, 0.32, 1)`       |
| `circ`   | `cubic-bezier(0.075, 0.82, 0.165, 1)`  |
| `expo`   | `cubic-bezier(0.19, 1, 0.22, 1)`       |
| `linear` | `linear`                               |

`easing` also accepts any raw CSS easing value. Try
`easing="cubic-bezier(0.34, 1.56, 0.64, 1)"` to let the node overshoot its
final size before settling.

## Notes

<Callout title="Scale cannot push siblings">
  The node animates `width` and `height`, not `transform: scale()`. A scaled
  element does not affect layout, so it would never displace the words. Growing
  the grid column is what moves them, and the artwork scales with its box.
</Callout>

<Callout title="The handles do not scale">
  Corner marks keep a constant `handleSize` while the frame grows, the way a
  real selection handle behaves. They sit outside the clipped artwork layer so
  the growing frame never crops them, and fade in as the node lands.
</Callout>

<Callout title="gapFrom sets the word spacing" variant="destructive">
  At rest the two words must read as one line. `gapFrom` applies on both sides
  of the node, so the initial separation is `gapFrom * 2` plus two pixels. Raise
  `fontSize` and you will need to raise `gapFrom` with it.
</Callout>
