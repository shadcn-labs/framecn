---
title: "Gradient Fill"
description: "A word-timed orange-to-pink gradient reveals left to right over white caption text."
---

## Usage

```tsx
import { CaptionGradientFill } from "@/components/framecn/caption-gradient-fill";
```

```tsx
<CaptionGradientFill />
```

## API Reference

### CaptionGradientFill

| Prop               | Type               | Default      |
| ------------------ | ------------------ | ------------ |
| `words`            | `CaptionWord[]`    | (demo words) |
| `fromColor`        | `string`           | `"#fe9f1b"`  |
| `midColor`         | `string`           | `"#ff2063"`  |
| `toColor`          | `string`           | `"#ef7aff"`  |
| `fontSize`         | `number`           | `80`         |
| `fontWeight`       | `number \| string` | `900`        |
| `background`       | `string`           | `"#0a0a0a"`  |
| `speed`            | `number`           | `1`          |
| `fps`              | `number`           | `30`         |
| `durationInFrames` | `number`           | `180`        |
| `width`            | `number`           | `1280`       |
| `height`           | `number`           | `720`        |
| `className`        | `string`           | `-`          |
