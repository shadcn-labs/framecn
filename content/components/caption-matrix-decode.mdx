---
title: "Matrix Decode"
description: "Green terminal captions decode through deterministic scrambled character states into readable words."
---

## Usage

```tsx
import { CaptionMatrixDecode } from "@/components/framecn/caption-matrix-decode";
```

```tsx
<CaptionMatrixDecode />
```

Render inside an Editframe `TimelineRoot`. The component reads its root `Timegroup`'s local playback time with `useTimingInfo`, so pause, restart, and backward seeking reproduce the same glyphs.
