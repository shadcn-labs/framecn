---
title: "Particle Burst"
description: "Uppercase captions brighten on speech and emit seeded, multicolored burst particles."
---

## Usage

```tsx
import { CaptionParticleBurst } from "@/components/framecn/caption-particle-burst";
```

```tsx
<CaptionParticleBurst />
```

Render inside an Editframe `TimelineRoot`. The root `Timegroup` is connected to `useTimingInfo`, and every dot position and text pulse is computed from local playback time. Backward seeking and restarting replay the same burst without timers or CSS keyframes.

## API Reference

### CaptionParticleBurst

| Prop               | Type               | Default      |
| ------------------ | ------------------ | ------------ |
| `words`            | `CaptionWord[]`    | (demo words) |
| `color`            | `string`           | `"#ffffff"`  |
| `burstColor`       | `string`           | `"#fbbf24"`  |
| `fontSize`         | `number`           | `80`         |
| `fontWeight`       | `number \| string` | `900`        |
| `background`       | `string`           | `"#0a0a0a"`  |
| `speed`            | `number`           | `1`          |
| `fps`              | `number`           | `30`         |
| `durationInFrames` | `number`           | `180`        |
| `width`            | `number`           | `1280`       |
| `height`           | `number`           | `720`        |
| `className`        | `string`           | `-`          |
