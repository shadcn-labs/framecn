## Usage

```tsx
import { CaptionTexture } from "@/components/framecn/caption-texture";
```

```tsx
<CaptionTexture />
```

## API Reference

### CaptionTexture

| Prop               | Type               | Default      |
| ------------------ | ------------------ | ------------ |
| `words`            | `CaptionWord[]`    | (demo words) |
| `textureFrom`      | `string`           | `"#ff6414"`  |
| `textureMid`       | `string`           | `"#ff2200"`  |
| `textureTo`        | `string`           | `"#ffd000"`  |
| `fontSize`         | `number`           | `120`        |
| `fontWeight`       | `number \| string` | `900`        |
| `speed`            | `number`           | `1`          |
| `fps`              | `number`           | `30`         |
| `durationInFrames` | `number`           | `180`        |
| `width`            | `number`           | `1280`       |
| `height`           | `number`           | `720`        |
| `className`        | `string`           | `-`          |

## Notes

<Callout title="Word timing is in seconds">
  The `start` and `end` fields on each `CaptionWord` are in seconds.
</Callout>
