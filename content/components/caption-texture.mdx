---
title: "Texture"
description: "Single-word captions with a moving, embedded rock-grain luminance texture and warm lava-color fill."
---

## Usage

```tsx
import { CaptionTexture } from "@/components/framecn/caption-texture";
```

```tsx
<CaptionTexture />
```

Render inside an Editframe `TimelineRoot`. The component attaches `useTimingInfo` to its root `Timegroup` and calculates the texture position, scale, and opacity from local playback time, including backward seeks and restarts.

## API Reference

### CaptionTexture

| Prop               | Type               | Default      |
| ------------------ | ------------------ | ------------ |
| `words`            | `CaptionWord[]`    | (demo words) |
| `textureFrom`      | `string`           | `"#ff6414"`  |
| `textureMid`       | `string`           | `"#ff2200"`  |
| `textureTo`        | `string`           | `"#ffd000"`  |
| `fontSize`         | `number`           | `120`        |
| `fontWeight`       | `number \| string` | `900`        |
| `background`       | `string`           | `"#0a0a0a"`  |
| `speed`            | `number`           | `1`          |
| `fps`              | `number`           | `30`         |
| `durationInFrames` | `number`           | `180`        |
| `width`            | `number`           | `1280`       |
| `height`           | `number`           | `720`        |
| `className`        | `string`           | `-`          |
