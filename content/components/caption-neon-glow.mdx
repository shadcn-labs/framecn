## Usage

```tsx
import { CaptionNeonGlow } from "@/components/framecn/caption-neon-glow";
```

```tsx
<CaptionNeonGlow />
```

## API Reference

### CaptionNeonGlow

| Prop               | Type               | Default      |
| ------------------ | ------------------ | ------------ |
| `words`            | `CaptionWord[]`    | (demo words) |
| `glowColor`        | `string`           | `"#00fff0"`  |
| `fontSize`         | `number`           | `80`         |
| `fontWeight`       | `number \| string` | `900`        |
| `wordsPerGroup`    | `number`           | `6`          |
| `background`       | `string`           | `"#0a0a0a"`  |
| `speed`            | `number`           | `1`          |
| `fps`              | `number`           | `30`         |
| `durationInFrames` | `number`           | `180`        |
| `width`            | `number`           | `1280`       |
| `height`           | `number`           | `720`        |
| `className`        | `string`           | `-`          |
