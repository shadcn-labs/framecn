---
title: "Matrix Decode"
description: "Random characters scramble and resolve into the target string."
---

## Usage

```tsx
import { MatrixDecode } from "@/components/framecn/matrix-decode";
```

```tsx
<MatrixDecode />
```

## API Reference

### MatrixDecode

| Prop               | Type     | Default                  |
| ------------------ | -------- | ------------------------ | --- |
| `text`             | `string` | `"DECRYPTED"`            |
| `charset`          | `string` | `"!@#$%^&\*()\_+-=<>?/\\ | "`  |
| `fontSize`         | `number` | `72`                     |
| `color`            | `string` | `"#22c55e"`              |
| `fontWeight`       | `number` | `600`                    |
| `revealDuration`   | `number` | `60`                     |
| `speed`            | `number` | `1`                      |
| `fps`              | `number` | `30`                     |
| `durationInFrames` | `number` | `90`                     |
| `width`            | `number` | `1280`                   |
| `height`           | `number` | `720`                    |
| `className`        | `string` | `-`                      |

## Notes

<Callout title="Random characters resolve to target">
  The decode effect uses random characters from a Matrix-style character set
  that gradually resolve to the target text. Longer texts take more time to
  fully resolve.
</Callout>
