---
title: "Spatial Push"
description: "A new scene physically presses the old one back into the frame."
---

## Usage

```tsx
import { SpatialPush } from "@/components/framecn/spatial-push";
```

```tsx
<SpatialPush />
```

## API Reference

### SpatialPush

| Prop                 | Type                                  | Default |
| -------------------- | ------------------------------------- | ------- |
| `from`               | `ReactNode`                           | `-`     |
| `to`                 | `ReactNode`                           | `-`     |
| `direction`          | `"up" \| "down" \| "left" \| "right"` | `"up"`  |
| `transitionStart`    | `number`                              | `-`     |
| `transitionDuration` | `number`                              | `30`    |
| `speed`              | `number`                              | `1`     |
| `fps`                | `number`                              | `30`    |
| `durationInFrames`   | `number`                              | `90`    |
| `className`          | `string`                              | `-`     |

## Notes

<Callout title="3D perspective push">
  The old scene is pushed back in 3D space while the next scene slides in from
  the chosen `direction`. Use `transitionDuration` to control how long the push
  phase takes.
</Callout>
