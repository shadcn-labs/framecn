---
title: "Scale Down Fade"

## Usage

```tsx
import { ScaleDownFade } from "@/components/framecn/scale-down-fade";
```

```tsx
<ScaleDownFade text="Scale down fade" />
```

| `fps`              | `number` | `30`                |
| `durationInFrames` | `number` | `90`                |
