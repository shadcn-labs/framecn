---
title: "Weight Shift"
description: "Lowercase captions hand bold emphasis from the first line to the second without shifting the layout."
---

## Usage

```tsx
import { CaptionWeightShift } from "@/components/framecn/caption-weight-shift";
```

```tsx
<CaptionWeightShift />
```

### CaptionWeightShift

| Prop               | Type            | Default                    |

| `color`            | `string`        | `"#ffffff"`                |
| `activeColor`      | `string`        | `"#ffffff"`                |
| `dimColor`         | `string`        | `"rgba(255,255,255,0.35)"` |
| `fontSize`         | `number`        | `72`                       |
| `background`       | `string`        | `"#0a0a0a"`                |
| `speed`            | `number`        | `1`                        |
| `fps`              | `number`        | `30`                       |
| `durationInFrames` | `number`        | `180`                      |
| `width`            | `number`        | `1280`                     |
| `height`           | `number`        | `720`                      |
| `className`        | `string`        | `-`                        |
